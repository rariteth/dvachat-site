Политика конфиденциальности приложения «Dvachat»

Редакция от 4 ноября 2026 года

«Dvachat» — рабочее приложение для сотрудников компаний, которые ведут переписку с клиентами через платформу чата поддержки. Приложение не предназначено для клиентов и не позволяет зарегистрироваться самостоятельно: учётную запись выдаёт администратор компании.

Какие данные обрабатываются

  • Учётные данные сотрудника — адрес электронной почты, имя и пароль. Пароль передаётся на сервер компании только при входе и в приложении не хранится; для дальнейшей работы используется токен доступа, который хранится в защищённом хранилище устройства (Keychain).
  • Переписка — сообщения, фотографии и файлы, которые сотрудник отправляет и получает в чатах. Для работы без сети приложение может сохранять копию последних сообщений и изображений на устройстве.
  • Токен push-уведомлений — идентификатор, который выдаёт Apple, чтобы сервер мог сообщать о новых сообщениях. Текст сообщений клиентов в уведомления не включается.
  • Фотографии — приложение получает доступ только к тем снимкам, которые сотрудник сам выбрал для отправки, и сохраняет в галерею только то, что сотрудник сам решил сохранить.

Где хранятся данные и кто их видит

Данные хранятся на сервере компании, к которому подключено приложение, и на устройстве сотрудника. Доступ к переписке определяется правами, которые сотруднику назначила компания. Данные не продаются, не передаются рекламным сетям и не используются для отслеживания. В приложении нет сторонних библиотек аналитики и рекламы.

Сроки хранения и удаление

При выходе из учётной записи или смене сервера приложение удаляет с устройства токен доступа, сохранённую переписку и очередь неотправленных сообщений. Данные на сервере хранятся по правилам компании-работодателя; удалить учётную запись и связанные с ней данные можно по запросу к администратору компании или по адресу ниже.

Персональные данные клиентов

Персональные данные клиентов, которые пишут в чат поддержки, обрабатывает компания, с которой клиент переписывается, по её собственной политике обработки персональных данных. Сотрудник видит их в приложении только в объёме, необходимом для ответа клиенту.
